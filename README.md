## 🎀 Mizuki Akiyama — 3D Web
**Mizuki Akiyama** An interactive 3D web project dedicated to **Mizuki Akiyama** from *Project SEKAI: COLORFUL STAGE! feat. Hatsune Miku* (25-ji, Nightcord de.).

## 🛠️ Feature
- Rotating 3D model when scroll
- Smooth scroll
- Music player
